# Котик и рыбки

Gray-box прототип для курса **«Проектирование и разработка игровых приложений»**.

**Играть:** https://wlyzxsd.github.io/cat_game/

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

## Что это за игра

Серый котик сидит на полу, а сверху падают рыбки и рыбьи скелеты. Котик ловит рыбок и старается не поймать скелет. Чем больше рыбок поймано, тем быстрее всё падает.

## Как управлять

| Клавиша | Действие |
|---|---|
| ← → или A / D | бег влево и вправо |
| Пробел | начать игру / начать заново после поражения |

## Что должен делать игрок

- ловить рыбок: каждая даёт **+1** к счёту;
- уворачиваться от скелетов: каждый пойманный скелет отнимает **1 жизнь** из 3;
- когда жизни закончились, игра заканчивается и показывает результат и рекорд;
- задача — побить свой рекорд.

## Что пока не реализовано

- нет звуков и музыки;
- рекорд не сохраняется после перезагрузки страницы;
- нет управления с телефона (только клавиатура);
- пропущенная рыбка ничем не наказывается;
- графика собрана из простых фигур, без спрайтов и анимации котика.

## Запуск

Нужен **Node.js 22 LTS** (или >= 20.19).

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run typecheck
npm run build
```

После push в ветку `main` игра автоматически публикуется на GitHub Pages через `.github/workflows/deploy.yml`.
